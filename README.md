# 🚀 Web Development Learning Hub

> A comprehensive, interactive, and beautifully structured roadmap and resource hub for mastering modern **HTML5**, **CSS3**, and **JavaScript (ES6+)**.

---

## 📌 About The Project

**Web Development Learning Hub** হলো একটি আধুনিক ও প্রোফেশনাল লার্নিং প্ল্যাটফর্ম, যা ওয়েব ডেভেলপমেন্ট শেখার যাত্রাকে একদম সহজ এবং সুসংগঠিত করার জন্য তৈরি করা হয়েছে। 

এখানে কোর HTML5 মার্কআপ থেকে শুরু করে CSS3-এর রেসপন্সিভ ডিজাইন এবং JavaScript-এর অ্যাডভান্সড অ্যাসিনক্রোনাস কনসেপ্ট পর্যন্ত সবকিছু ধাপে ধাপে, রোডম্যাপ আকারে সাজানো রয়েছে। প্রতিটি টপিকের সাথে নিখুঁত ব্যাকগ্রাউন্ড থিওরি, কোড এক্সাম্পল এবং লাইভ আউটপুট প্রিভিউ যুক্ত করা হয়েছে।

---

## ✨ Key Features

- 🗺️ **Complete Master Roadmaps:** HTML5, CSS3, এবং JS (ES6+)-এর পূর্ণাঙ্গ ও নিখুঁত লার্নিং পাথ।
- 💡 **Interactive Code Examples:** প্রতিটি কনসেপ্টের জন্য প্রাতিষ্ঠানিক ও বাস্তব জীবনের কোড স্নিপেট।
- 📱 **100% Fully Responsive Design:** মোবাইল, ট্যাবলেট এবং ডেসকটাইপ—সব স্ক্রিনে মসৃণ নেভিগেশন।
- 🎨 **Modern Dark UI/UX:** চোখের জন্য আরামদায়ক ও আকর্ষণীয় ডার্ক মোড ডিজাইন।
- 🚀 **Zero External Dependencies:** পিওর নেটিভ টেকনোলজি ব্যবহার করে ফাস্ট লোডিং স্পিড নিশ্চিত করা হয়েছে।

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure, Canvas, Media API)
- **Styling:** Modern CSS3 (Flexbox, CSS Grid, Custom Properties, Animations)
- **Scripting:** Modern JavaScript (ES6+, DOM Manipulation, Async/Await, Fetch API)

## 🚀 How to Run Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start local development server:**
   ```bash
   npm run dev
   ```

3. **Verify build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```
